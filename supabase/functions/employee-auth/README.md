# 직원 비밀번호 로그인

- 직원의 첫 비밀번호는 `000000`. 직원 계정은 최초 로그인 시 기본값으로 생성됩니다.
- 숫자 6자리만 허용하며 기본 비밀번호로 로그인한 세션은 변경/로그아웃만 할 수 있습니다. 새 비밀번호에 `000000`은 사용할 수 없습니다.
- 관리자와 마스터는 `계정 관리`에서 초기화할 수 있고, 조회 응답의 PIN 값은 마스터 모드에만 포함합니다. 관리자 테스트 모드에서는 초기화할 수 없습니다.
- 비밀번호는 마스터 조회 요구에 따라 별도 `nd_employee_accounts` 테이블에 복원 가능한 값으로 보관합니다. 공개 근무표 payload나 클라이언트 저장소에 보관하지 않습니다. 테이블 접근은 service_role만 가능합니다.
- 변경/초기화와 모든 기존 세션의 폐기는 하나의 DB 트랜잭션입니다. 브라우저는 재실행·포커스 복귀·30초 주기로 세션을 확인합니다. 세션은 30일간 유지됩니다.
- 기존 관리자/마스터 모드 비밀번호는 변경하지 않습니다. 이 기능은 직원 로그인 계정의 비밀번호입니다.
- 근무 교환 API도 직원 비밀번호 변경이 완료된 세션을 확인합니다. 레거시 근무표 API 전체를 새 인증 구조로 이관한 것은 아닙니다.
- 배포: `employee-auth.sql` 적용, employee-auth 및 work-swap 함수 배포, HTML/employee-auth.js/css/work-swap.js 배포.
- 검증: test-auth.mjs, test-auth-db.sql(롤백), verify-auth-live.cjs. 실제 직원 비밀번호를 설정하거나 초기화하는 테스트는 하지 않습니다.
